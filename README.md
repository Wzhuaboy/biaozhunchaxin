## 搜索：同系列与采用关系

- 搜标准号会自动带出同系列：搜 `10963` 出现 10963.1 / 10963.2 / 10963.3，搜 `10963.1` 也会带出 10963.2、10963.3
- 搜标准号会自动带出采用关系对照：搜 `10963` 会出现 IEC 60898-1，搜 `60898` 也会反向出现 GB/T 10963.1；每行“采用”栏点链接可直接跳转对照方
- 采用关系分等同采用（IDT）与修改采用（MOD），以官网详情页采标信息为准；国标采标旧版 IEC 时会单独注明（例如 GB/T 14048.2-2020 采标 IEC 60947-2:2016，而 IEC 现行版是 2024）
- 搜索按词边界匹配：搜 `2423` 不会带出 62423，搜 `CTI` 不会带出 detection；关键词（针焰、灼热丝、CTI、盐雾）只匹配本类试验方法
- 搜 `2423` 会出现 GB/T 2423 全系列 18 条和对应的 IEC 60068-2 各版；搜 `湿热` 只会命中 2423.3 / 2423.4 与 IEC 60068-2-78 / 60068-2-30，不会带出盐雾；搜 `球压` 出现 5169.21 与 IEC / EN 60695-10-2 共 5 条
